# 🇰🇼 أداة أتمتة تصاميم أخبار محافظات الكويت

أداة ذكية وسريعة للغاية صُممت خصيصاً لتوليد التصاميم الإخبارية اليومية لمحافظات الكويت الست (**العاصمة، حولي، الفروانية، الأحمدي، مبارك الكبير، الجهراء**) بالدمج المباشر مع قوالب كانفا المفرغة أو القوالب الجاهزة المدمجة.

---

## 🚀 طريقة التشغيل السريع (بنقرة واحدة)

### الخيار 1: تشغيل الواجهة التفاعلية (Web UI)
- اضغط مرتين على ملف **`run.bat`**
- سيفتح المتصفح تلقائياً على الرابط: `http://127.0.0.1:5000`

أو عبر موجه الأوامر:
```bash
python app.py
```

### الخيار 2: سطر الأوامر المباشر (CLI)
لتوليد تصميم فوري من التيرمينال أو ربطه مع أي بوت/سكريبت آخر:
```bash
python generate_cli.py --gov capital --title "عنوان الخبر الرئيسي" --body "تفاصيل أو ملخص الخبر" --image "مسار_الصورة.jpg" --tag "عاجل"
```

المعرفات المتاحة للمحافظات:
- `capital`: محافظة العاصمة
- `hawalli`: محافظة حولي
- `farwaniya`: محافظة الفروانية
- `ahmadi`: محافظة الأحمدي
- `mubarak`: محافظة مبارك الكبير
- `jahra`: محافظة الجهراء

---

## 🎨 كيف تدمج تصاميمك الحالية من كانفا (Canva) بنسبة 100%؟

لكي يظهر التصميم تماماً كنسخة كانفا الخاصة بك:
1. افتح تصميم المحافظة في كانفا.
2. احذف فقط نص الخبر والصورة المتغيرة، واترك الهوية والإطار والشعار وشريط المحافظة.
3. اضغط **Share** -> **Download** واختر:
   - File type: **PNG**
   - فعّل خيار: **Transparent background** (خلفية شفافة).
4. سمّ الملف باسم المحافظة بالإنجليزية:
   - `capital.png`
   - `hawalli.png`
   - `farwaniya.png`
   - `ahmadi.png`
   - `mubarak.png`
   - `jahra.png`
5. ضعه في مجلد `templates_overlay/`، أو ارفعه مباشرة من صندوق **"استبدال قالب المحافظة"** أسفل صفحة الويب!

---

## 📁 هيكل مجلدات المشروع

- `engine.py`: محرك معالجة الصور والتصميم وتنسيق الخطوط العربية (يدعم التفاف الأسطر وتشكيل الحروف).
- `app.py`: خادم واجهة الويب التفاعلية.
- `templates/index.html`: صفحة الواجهة البصرية الأنيقة.
- `templates_overlay/`: مجلد إطارات وقوالب المحافظات الست الشفافة (PNG).
- `fonts/`: الخطوط العربية المستخدمة للكتابة.
- `output/`: المجلد الذي تُحفظ فيه الصور المنتجة عالية الجودة (1080×1080).
- `run.bat`: ملف التشغيل الفوري لويندوز.
